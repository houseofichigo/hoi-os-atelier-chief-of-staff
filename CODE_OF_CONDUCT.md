# Code de conduite

Ce projet accueille les contributions respectueuses, concrètes et orientées vers l'apprentissage.

- Respecter les personnes, leurs contextes et leur niveau technique.
- Critiquer les idées et les changements, jamais les personnes.
- Ne publier aucune donnée personnelle ou confidentielle.
- Signaler les problèmes de sécurité en privé.
- Refuser le harcèlement, la discrimination, les menaces et les contenus délibérément trompeurs.

Les mainteneurs peuvent modérer ou refuser toute contribution contraire à ces règles. Pour signaler un comportement, utiliser un canal privé de l'organisation qui héberge le dépôt.
